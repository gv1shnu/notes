The 5NF phantom row

The UI computes the phantom row for the current seed: it builds the two-way join and finds a row that isn't in the real participation set, then prints it ("joining only Student_Club and Student_Event would invent …").

If no phantom exists, the example is wrong and 5NF is meaningless. selftest.js fails the build in that case.

UI pieces

  • Progress nav: 7 pills; Next / Back / Reset buttons; keyboard friendly; #statusAnnouncer is an aria-live region announcing the step.
  • Before/After split: input snapshot left, outcome right; changed tables open, carried-forward tables in <details>.
  • Split banner: "Campus_Record_1NF → Student_Profile_2NF + Course + Enrollment_2NF" and a Columns moved cue listing each column's destination.
  • Key chips: PK on key columns; FK → Table only if that table exists in the same snapshot (FK_OWNERS map).
  • Glossary: tooltip buttons for "Fact" and "Dependency" (→, ↠, ⋈ explained).
  • Seed box: type any seed or roll a new one to practise on fresh values.
