How I judge it

$ node selftest.js PASS: 8 seeds; deterministic schemas, unique primary keys, complete snapshots, and lossless 2NF–5NF decompositions.
  • Seeds tested: 240519, 1, 42, 99, 987654, 314159, 0, "abc".
  • Checks: same seed → same model; schema identical across seeds; no empty tables; no duplicate PKs; 2NF, 3NF, BCNF, 4NF joins rebuild the input exactly; 5NF two-way join is not enough but the three-way join is; pair tables are true projections; every table appears in the right input/outcome HTML.
  • Teaching metric: can a student say which column moved where, and why, at each step?

Rebuild it from scratch

  1. Design the case study on paper first
    Pick entities (student, dept, course, tutor, hobby, language, club, event). For each normal form, write the one dependency that violates it. Make sure the data really shows each anomaly, especially the 5NF phantom.
  2. Deterministic generator
    FNV-1a hash of the seed → mulberry32 → Fisher–Yates shuffle of name pools. Keep the relationships as fixed index arrays.
  3. States as data
    databaseStates(m) returns 7 arrays of {title, columns, rows, key}. Reuse objects for carried-forward tables.
  4. Self-test before UI
    Load app.js in Node's vm with a fake DOM; re-join tables and compare as row sets.
  5. Render
    A table() template with PK/FK chips, a split view, a move cue, collapsible carried tables.
  6. Navigation + a11y
    Progress pills, Next/Back/Reset, aria-live announcer, scroll into view.
  7. Ship
    Push to main; Pages from root.
