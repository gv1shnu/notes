the build pipeline, stage by stage

build.sh, in order

  1. Stage
    rsync the plaintext site into .enc-build/site, excluding every tooling/meta file by name so it can never be obfuscated and shipped as cleartext.
  2. Obfuscate paths
    obfuscate.js renames dirs/files to tokens and rewrites all internal links (index.html keeps its name; assets keep generic names, parents get tokens).
  3. Strip residue
    strip-residue.js removes leftover identifying bits from the staged tree.
  4. Inline assets
    inline-assets.js folds CSS/JS/images into each page (data URIs), rebuilds any retired SPA shells as static link pages, and sweeps orphan files.
  5. Build search
    build-search-index.js indexes the obfuscated tree and injects it into index.html's placeholder.
  6. Encrypt
    StatiCrypt AES-256-encrypts every page's content with the shared salt.
  7. Sessionize
    sessionize-staticrypt.js converts StatiCrypt's persistent "remember me" into a per-tab sessionStorage key.
  8. Publish
    copy ciphertext to docs/; then verify.sh gates; then a sequential commit + push.

Why paths are KDF-derived, not hashed

key = scrypt(PASSWORD, salt from .staticrypt.json, 32B) token = HMAC-SHA256(key, "path:" + sourceRelPath)[:16 hex] • same salt StatiCrypt uses → tokens deterministic per password • a new password reshuffles EVERY token • password never used directly as an HMAC key • scrypt is memory-hard → no raw-hash-speed brute force even if a (plaintext path, token) pair leaks

A plain hash of the path would be brute-forceable at billions/sec; routing it through scrypt first means an attacker who somehow learns one mapping still can't cheaply recover the password or other paths.

index.html must keep its name for directory-default serving and the home link — so that one name is deliberately not tokenised.

The verification gate (verify.sh)

Runs on the built docs/ and exits non-zero (printing every failure) if anything could leak. It strips long base64/hex ciphertext runs to a "shell" first, so greps can't false-positive on random ciphertext:

#check
1only *.html and .nojekyll may exist in docs/
2every page has a StatiCrypt payload (staticryptEncryptedMsg…)
3outer metadata is neutral: title is exactly "Private notes"; no description, no OpenGraph/Twitter tags
4no source fragments in cleartext (topic slugs, requirements.txt, .mjs, /learn/, taxonomy ids…)
5no email, no PRIVATE KEY header, no credential assignment in cleartext

Written for bash 3.2 (macOS default); reads no secrets and prints none. publish.sh aborts before git add if it fails.
