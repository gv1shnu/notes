How I judge it

  • Mode correctness: python test_modes.py → [modes OK].
  • Turn latency: per-model generation + reload; the 23 GB Qwen is the known outlier on 16 GB VRAM.
  • Conversation quality: do they reference each other by name, disagree, and stay in persona without name prefixes?

Rebuild it from scratch

  1. Environment
    Python 3.12 venv; pip install ollama PyYAML; pull 2–3 models that fit your VRAM.
  2. Config
    config.yaml → dataclasses Participant(name, model, voice, persona), Conversation(...), Voice(...).
  3. Transcript
    a list of Turn(speaker, content) with tail(n) and as_text(n).
  4. LLM wrapper
    ollama.Client(host).chat(model, [system, user], options={temperature}).
  5. Orchestrator
    system prompt from persona + others; round() branches on mode; write the stub-LLM test first.
  6. CLI loop
    topic → auto_rounds rounds → prompt the user (Enter / text / /voice / /quit).
  7. Voice
    add kokoro + sounddevice for TTS, faster-whisper for STT; import lazily behind the config flags.
