The problem

One chatbot talking to itself has one reasoning style. I wanted a table of different models, each with a persona and a voice, debating a topic out loud while I sit in and interject, fully offline: no cloud, no keys, no per-token cost.

Who sits at the table

What I observed

  • Turns are sequential, so only one model is loaded at a time: you need VRAM for the largest single model, not the sum.
  • On my reference RTX 3080 Ti Laptop (16 GB VRAM), qwen3.6 (~23 GB) spills into system RAM and is by far the slowest turn; the others stay on GPU.
  • The ML/audio stack (torch, kokoro, faster-whisper) had no wheels for newer Pythons: pin to 3.12.
  • Models drift into prefixing their own name and writing stage directions. The system prompt has to forbid both.
  • "Debate" and "independent opinions" are different products, so the context mode became a config switch.

controls

Type a topic to start. After each round: Enter = let them continue, type = join in, /voice = speak, /quit = stop.
