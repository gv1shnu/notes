content pipeline, trust boundary, and the XP economy

Content pipeline: split at the trust boundary

Grade flow (a submission)

  1. Practice (Run)
    Student query runs in the PGlite worker against visible sample data. Instant, free, unlimited, and never scored.
  2. Submit
    The query + the player's Supabase JWT go to the judge RPC.
  3. Execute safely
    A restricted read-only executor role runs the query against the hidden fixtures (3 cases). Any safe query matching all result sets passes — intended syntax isn't required.
  4. Record
    A separate server identity applies the XP/unlock transaction. Wrong answers cost nothing; the local Run state is ignored.
  5. Progress
    Server returns the authoritative state (solved, XP, next unlock, isAdmin). The client learns admin status only from the server.

The XP economy (anti-bypass)

start 100 XP survey +5 solve a ruin +20 first clue free deeper clue −5 (ruins 11–20) full reveal −15 (after all clues opened) ---------------------------------------- no-help ceiling MAX_XP = 600 full-help end FULL_HELP_END = 250 revisits non-scoring, analytics only wrong answer 0 (never penalised)

Help is staged: free result diagnostics name the kind of mismatch; the first clue removes the fear of asking; stronger help costs XP so it stays visible in the final score without ever stopping progress.

XP, solved state and unlocks are server-authoritative in production; the browser's copy is a display cache.

Leaderboard = completers only (all 20 solved), ranked by XP then time from sign-up to completion; no email shown.

The 3D world

  • Seven districts (Yamuna Gates → Deep Foundations), contiguous ruin ranges named in ruins.ts.
  • Twenty hand-built levels (fortress, bus depot, riverfront, vault, bazaar…), each with its own ambience track.
  • Infinite tiled landscape (toroidal tiling of the asset kit), an animated Soldier avatar, guide arrows, fullscreen.
  • An animated geographic atlas: players see only cleared parcels; admins inspect all 20.
  • No paid map API; original asset kit (see CREDITS).
