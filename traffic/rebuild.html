Decisions

Pending / known limits

  • Validate on representative real Indian fixed-camera video with independently reviewed cause labels.
  • Two-wheeler + autorickshaw detection (not distinct COCO classes) — a custom-trained model.
  • Multi-event reporting (currently only the highest-severity interval).

Rebuild it from scratch

  1. Async spine
    FastAPI for uploads/status/evidence; PostgreSQL for jobs/tracks/incidents; Redis + Celery for inference; SSE for progress.
  2. Vision package
    Validate + normalize video; YOLO11n + ByteTrack on time-sampled frames (sequential to keep tracking state); keep original frame indices + normalized timestamps.
  3. Movement + congestion
    Displacement ÷ box size over a 1-s baseline; per-region queue detection with the thresholds above and dropout tolerance.
  4. Attribution
    Rank candidates by precedence/position/followers/propagation/tracking quality; gate hard so weak evidence returns unknown.
  5. Plates
    A separate plate YOLO on candidate vehicles → EasyOCR with multi-frame consensus and Indian formats; reject nulls.
  6. Evidence + review
    Annotated frames, before/during/after, an MP4 clip, a seekable timeline, and append-only human review; versioned JSON report with model checksums.
  7. Workflow + persistence
    Wire the stages as a LangGraph StateGraph; checkpoint tracking atomically; advisory-lock jobs; snapshot config into each job.
  8. Package + evaluate
    Docker Compose (loopback frontend); build a rendered-3D scenario set with ground truth to score end-to-end; publish a static showcase.
