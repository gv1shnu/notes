What counts as congestion

congestion requires ALL of: ≥ 4 vehicles low median motion high stationary fraction road occupancy (union of boxes in a road raster) temporal persistence (queue growth corroborates onset) dropout tolerance 0.6s → occlusion dips don't reset the timer already-congested clips need 2× the persistence window movement = displacement/sec ÷ mean box size (not km/h)

Movement is relative by design: without camera calibration you can't claim km/h, so the system normalises displacement by bounding-box size and refuses to invent speed.

occupancy is a union of boxes, so overlapping vehicles aren't double-counted.

Cause attribution: built to say "unknown"

  • Missing precedence or follower response caps the score below 0.5.
  • Without road regions, scores cap at 0.59 and can't pass the 0.62 selection threshold.
  • Similar top scores → unknown; a leading candidate below min_tracking_quality (0.65) → unknown, kept first in alternatives.
  • Tracking quality = share of expected samples present × a box-stability term (falls when a box jumps = track latching onto another object). Separate from detector confidence.

Crash-safe, idempotent jobs

  • Tracking checkpoint via atomic temp-file replace; reused on retry; other deterministic stages replay from it.
  • Postgres advisory locks prevent concurrent runs of the same job; Celery uses late-ack + prefetch 1.
  • Camera config + thresholds are snapshotted into the job, so a later edit never silently changes an old result; model checksums + config version appear in the report.
  • Extend via interfaces: DetectorTracker, CauseDetector.category(), the OCR protocol, LocalStorage — unsupported classes never become fake detections.
