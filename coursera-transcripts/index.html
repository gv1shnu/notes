The problem

I learn best from text I can search and re-read, but Coursera gives me video. Opening every lecture, clicking the transcript tab, copying the text, and filing it by module is tedious and I do it for whole courses.

So: a script that logs in once, walks a course outline, and exports every lecture's transcript as tidy, organised Markdown.

Two phases

What I observed

  • Login must be manual and one-time: the script opens Brave with a dedicated profile, pauses until I'm signed in, then runs itself.
  • Coursera's transcript DOM varies, so extraction needs a ladder of fallbacks: structured cue phrases → container innerText → a last-ditch JS scan.
  • The transcript text is polluted: zero-width chars, NBSPs, and the player's a11y label "Play video starting at :1:24 and follow transcript" injected into the words. All stripped.
  • A long run will be interrupted. State files (last completed / last processed) let it resume exactly where it stopped.
  • Lectures with no transcript aren't failures: they go to a manual_items list, separate from real failed_items.
