How I judge it

  • Extracted / total per course (printed at the end; 59/59 on MongoDB).
  • Manual + failed counts small and explained by their lists.
  • Readability: paragraphs, no zero-width junk, no player labels bleeding into text.
  • Resumability: killing and restarting continues from the cursor, doesn't redo work.

Rebuild it from scratch

  1. Browser session
    Playwright launching Brave with a persistent profile dir, or connect_over_cdp to a running browser; an is_logged_in heuristic + a pause-for-login helper.
  2. Discovery
    Open the course home, expand every collapsed week/module, harvest lecture links and titles into an ordered list; save to JSON.
  3. Resume
    Read the last-completed cursor and start the loop after it; --restart ignores it.
  4. Per lecture
    goto → click the transcript tab → run the extraction ladder → sanitize → build plain + timestamped forms.
  5. Write
    NN_module/NNN_lecture.md with a header; append to failed/manual lists on misses; screenshot on error.
  6. Index + summary
    Write 00_index.md and print the Extracted/Manual/Failed tally.
  7. Flags
    --discover-only, --limit, --timestamps, --cdp-url.
