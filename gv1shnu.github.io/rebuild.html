Decisions

decisionwhytrade-off
Static files on GitHub Pages + CNAMEfree, fast, nothing to patch, and my domain stays the addressno server-side anything; the analytics come from a third-party snippet
Vanilla JS, no framework or buildfour effects don't need React; view-source shows exactly what runssome repeated boilerplate (resize debounce, reduced-motion check) in each script
One canvas effect per pageeach page has its own mood without one huge scriptthree separate animation loops to look after
Log lines live in a text fileI can change the tone without touching codean extra fetch (preloaded in <head>)
Folder per page with its own index.htmlclean URLs, and the CSS/JS stay next to their pageshared bits (favicons, meta) get copied into each page
defer on scripts; FPS capped at 30first paint isn't blocked, and laptops don't spin their fans up for a portfoliothe animation is slightly less smooth
Honour prefers-reduced-motionthe theme is loud, but it should still be accessibleapplied to the timeline, the contact page and the disco CSS so far; the home avatar still animates

How I judge it

  • Tells the story in about 5 s: name, "Assistant Professor of CS and Certified Ethical Hacker", and then the log stream shows the rest.
  • Weight: about 3,270 lines of hand-written HTML/CSS/JS across three pages, plus one icon font.
  • Shares well: the OG/Twitter cards render a proper preview card on any chat app.
  • Stays current: 9 projects on the timeline so far; adding another one is a single div.timeline-item.project.

Rebuild it from scratch

  1. Repo + domain
    Create <user>.github.io, enable Pages from the default branch, and add a CNAME file with your domain plus a DNS CNAME record pointing at GitHub.
  2. Folders
    index.html + homepage/, then timeline/index.html and contact/index.html, each with its own css/js. Put the favicons and site.webmanifest in favicon/.
  3. Home layers
    A full-screen canvas at z 1, the log div above it, the UI at z 50, and a hidden spectrum div behind everything.
  4. Log stream
    Fetch logz.txt, parse it with /^\[(\w+)\]\s*(.*)/, prepend one line every 300–1000 ms, cap the stack at five, and give each line a colour that isn't on screen yet.
  5. Avatar
    Draw a chair, desk, monitor and a stick body with lineTo. Keep a state variable that cycles coding/gaming/writing and changes the pose and glow colour; a "git push" line forces a 2.5 s dab.
  6. Timeline
    Items get classes edu|work|project under .timeline-year headers. Filter buttons hide the items, then hide any header left with nothing visible. Add a starfield canvas behind it.
  7. Contact
    Matrix rain (column drops plus a translucent black fill for the trails), then type out each data-type line and fade in the links.
  8. Ship it
    Add the description, canonical and OG/Twitter meta, defer on every script, a reduced-motion check in each effect, then push.
