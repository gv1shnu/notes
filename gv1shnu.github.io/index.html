The problem

I needed one address that says who I am in a few seconds: a CS teacher, an ethical hacker, someone who lives in databases. A plain résumé page doesn't say any of that.

So the site is a little hacker terminal. You get a stick-figure me at a desk, a log stream that scrolls past what I actually spend my days on, and a whoami card for anyone who wants the real introduction. It's three static pages on GitHub Pages behind my own domain. No framework and no build step.

Three pages, three moods

What I observed while building it

  • The log stream is the personality. homepage/logz.txt has 52 tagged lines ([HACK], [SEC], [DB], [TEACH], [GAME]…). Editing that file changes how the site feels, and I don't have to touch any code.
  • Easter egg: whenever a git push line scrolls past, the avatar drops what it's doing and dabs in magenta for 2.5 s.
  • Profiles got pruned. One commit called "close profiles" took the X link off the contact page and renamed "IMF_PROTOCOL / Agent:" to a plain "Contact". The site grew up a bit there.
  • The timeline is the living part. New projects get added as they ship: Web Timeline in August, Dilli Khoj in September.

cheap to run

Static files, one custom domain and a GoatCounter snippet for page views. Nothing to patch and nothing to keep paying for.
