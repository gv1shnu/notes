Decisions

decisionwhy
Virtual points onlymotivation game, not gambling; no money, no regulation
Proportional payouts (not winner-take-all)small challengers still get a fair share; no whale dominance
Jury Tribunal, first to 3disputes resolved by neutral users, not an admin
No-trapped-funds failsafea stalled review auto-wins for the creator; explicitly tested
Follow-gated challengesstops strangers piling on; ties stakes to the social graph
AI moderation at creationkeep bets personal, actionable, safe — not predictions/abuse
Ollama → Groq for the LLMa hosted model so the deploy doesn't need a local GPU
Layered routers → services → modelsbets grew too big; splitting crud/challenges/resolution kept it testable
Auto-seed demo datathe app looks alive on first run; off in production

How I judge it

  • Economy correctness: payouts sum to the pot; proportional shares are exact (test_payouts).
  • Failsafes: no challenge can ever trap points (test_failsafes).
  • Moderation quality: bad bets (predictions, abuse) rejected with a reason (test_llm_validator).
  • Deadline handling: expired bets resolve without manual action.

Pending

Rebuild it from scratch

  1. Data model
    Users (points, follows), Bets (stake, deadline, status, proof), Challenges (stake per challenger), a validation queue, notifications, disputes/jury votes.
  2. Auth
    JWT OAuth2 password flow; a passphrase-gated admin area.
  3. Economy in services
    bet_service / challenge_service: compute the pot, proportional payouts, tribunal resolution, and the no-trapped-funds failsafe — write these tests first.
  4. Lifecycle
    create → challenge (follow-gated) → prove → verify → tribunal; a deadline checker that resolves expired bets.
  5. Moderation
    A LangGraph agent over Groq (JSON mode): is the bet personal, actionable, safe? Lazy-instantiate the client. A fast pre-check first.
  6. Social + feed
    Follow graph, stars, activity feed, notifications, proof-upload and review pages.
  7. Frontend
    React + Tailwind pages for feed/profile/notifications/review/disputes/admin.
  8. Seed + deploy
    Auto-seed demo users/bets across every state (off in prod); FastAPI under gunicorn/uvicorn; Postgres via Docker.
