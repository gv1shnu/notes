Blueprint

ingest once, converse forever

Ingest: media → a corpus of clips

  1. Extract dialogue
    Pull the dialogue track — the centre channel on 5.1, a downmix otherwise — with ffmpeg.
  2. Get the text
    If the file ships an English subtitle, read its cues and skip transcription; else run whisper-cli with auto language detection.
  3. Second pass
    When whisper covers little of a file (common with non-English audio), hand the same clip to macOS's on-device Speech recogniser and add the phrases it missed.
  4. Cut + normalise
    Cut clean phrases from a 48 kHz master with 10/12 ms fades, normalised per source — leaving a few dB of variance on purpose.
  5. Embed
    Embed distinct phrases with nomic-embed-text so replies can match by meaning; store clips in SQLite with audio on disk.

clip ids were widened to avoid collisions during ingest; clip timing was fixed so ingest doesn't abort on early words.

Conversation: message → spliced reply

The one line that is the whole aesthetic

for each clip in the reply: play 48kHz phrase (10/12ms fades) insert tuning static + a small gap ── route EVERYTHING through ── one ~1150 Hz band-pass filter (never per-clip, never optional) seed → identical splice every time export: re-render offline → WAV + SRT

Because every borrowed voice passes through the same narrow band, their timbres collapse toward one another and the result reads as a single broken radio, not a mixtape.

all randomness is seeded, so a reply is reproducible — the foundation of the offline WAV+SRT export.

The receiver faceplate

  • A clock-synced receiver faceplate with a tuner dial (decluttered when there are many sources), a live spectrum on the right wall, and the Bumblebee face.
  • A terminal types the reply in sync with the audio and names the station each fragment came from; alternating-italic reply text; replay.
  • Corpus stats, reply latency and credits shown on the radio; Setup and Library screens are scrollable.
  • Robustness: survive missing clips, let the audio context use the device sample rate, stop the engine only on unmount (a bug that caused silent playback).
