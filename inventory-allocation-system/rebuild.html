Decisions

decisionwhytrade-off
Everything in one POST /orderthe brief: more than one API is an automatic fail, and splitting check/deduct into separate calls is exactly how races happenno way to list products or orders from the API
Rules only in services/the controller stays HTTP-only, so the logic can be tested without Expresserror identity crosses the boundary as a string
Sequelize managed transactionautomatic commit/rollback; the read and write share one unit of workthe transaction has to be passed into every repository call by hand
SQLitezero setup for a reviewer: npm install && node index.jsa single writer, so it serializes rather than scales
Rejections roll back with no order rowthe Order table only ever holds real allocationsno audit trail of failed attempts
Minimal React form, no stock logic in itthe brief forbade frontend stock handling; the server's message is shown as-isthe backend URL is hard-coded

Rebuild it from scratch

  1. Init
    npm i express sequelize sqlite3 cors; index.js listens on 4000 and requires src/app.js.
  2. Models
    models/index.js creates the Sequelize instance (dialect sqlite, storage ./database.sqlite). Define Product(id, name, stock) and Order(id, productId, quantity, status), then sequelize.sync().
  3. Repositories
    Thin wrappers: findById(id, t), updateStock(id, n, t), create(data, t). They always accept the transaction.
  4. Service
    placeOrder inside sequelize.transaction(async t => …): find, 404-error if missing, error if stock < qty, update, create with status SUCCESS.
  5. Controller
    Reject a missing productId/quantity or quantity ≤ 0 (400). Call the service, return 201, and map the two error messages to 404 / 400, everything else to 500.
  6. Route
    router.post('/', createOrder) mounted at /order; express.json() and cors() on the app.
  7. Frontend
    npx create-react-app frontend: two inputs, one button, POST the numbers, and print data.message.
  8. Prove it
    Seed stock 5, order 3 twice and expect 201 then 400. Then fire N parallel orders and check that stock never goes below zero.
