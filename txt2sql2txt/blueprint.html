Request flow

Offline SQL → text: walking the AST

new NodeSQLParser.Parser().astify(sql, {database:"postgresql"}) returns one AST or an array (multiple statements, joined with ---). Then explainStatement switches on ast.type:

  • select: summary line + one bullet per clause: Distinct, Selects, From (with joins), WHERE, GROUP BY, HAVING, ORDER BY, LIMIT
  • insert: table, columns, number of value rows
  • update / delete: table, SET pairs, WHERE; with no WHERE it shouts "all rows — no filter!"
  • anything else: one-line summary + "use the LLM engine"
OP_WORDS maps operators to English: = → "is" != / <> → "is not" > → "is greater than" … litText() literal / column ref → text aggrText() COUNT(x) → "the count of x" condText() recursive for AND / OR trees

Offline text → SQL: four patterns, in order

#regex shapeexampleoutput
1top N <table> by <col>top 5 customers by spendSELECT * … ORDER BY spend DESC LIMIT 5
2how many | count of | number of <t> [where …]count of ordersSELECT COUNT(*) AS count FROM orders
3avg|sum|min|max|total <col> of <t> [by <col>]average total of orders by statusSELECT status, AVG(total) … GROUP BY status
4show|list|get|all <t> [where …]list customers where country = USSELECT * … WHERE country = 'US'

resolveTable(word) maps the word to a real table from the CREATE TABLEs in the schema box: exact → naive plural (±s) → substring → raw word. naiveWhere rewrites "is / is not / greater than / at least…" to operators and quotes a bare word on the right side (keeping its case).

In-browser Postgres + provider adapter

PGlite lifecycle

  1. first load: await import(PGLITE_URL) (lazy, so the page opens fast)
  2. every dataset/file load: a fresh in-memory new PGlite()
  3. db.exec(sql) runs schema + seed
  4. extractDDL copies the CREATE TABLE…; blocks into the schema box, which becomes LLM context

samples.js sets window.SAMPLE_DATASETS via a script tag, so it works even from file:// (no fetch, no CORS).

callLLM(system, user): three shapes

  • OpenAI-compatible (OpenAI, OpenRouter, Groq): one code path, Bearer key; OpenRouter also gets HTTP-Referer + X-Title
  • Anthropic: /v1/messages + anthropic-dangerous-direct-browser-access header for CORS
  • Gemini: :generateContent?key= with system_instruction
