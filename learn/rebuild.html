How I judge it

  • Validator clean: npm run validate exits 0 (JSON valid, enums, difficulty range, unique ids/URLs, no orphans).
  • Links alive: npm run check-links; dead resources become DEAD with a backup.
  • Coverage: every concept has a quiz (67/67) and practice rooms (62/67).
  • Learner progress: dashboard counts by status; quiz pass mark 70%.

Rebuild it from scratch

  1. Write the spec + taxonomy
    Tree of areas (foundations, security foundations, offensive, defensive…). Fix the concept schema above before writing content.
  2. Author JSON + validator together
    validate.mjs: parse every file, enums, ID_RE kebab ids, dates, duplicates, and resolve every cross-reference.
  3. Loader + router
    Fetch manifest, then datasets in parallel; hash router that calls resolve(path, params) and mounts {html,title,onMount}, focusing main.
  4. Storage
    IndexedDB wrapper (open, tx, get/set/delete/getAll); progress module loads all into memory at init and writes through.
  5. Views
    Home, path, concept list/detail, quiz, roadmaps, dashboard (with export/import), reference pages, search.
  6. Search
    Token scoring + synonyms from the manifest.
  7. Practice mapping
    Convert the room CSV, weighted-match to concepts, write thm-practice.json.
  8. Ship
    .nojekyll, Pages from root; npm run serve locally (module scripts need HTTP).
