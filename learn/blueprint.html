Data model: the concept graph

concept { id, title, category → taxonomy node difficulty 0..6, importance prerequisites[] → concept ids summary, description, whyItMatters, mentalModel offensive[], defensive[], ctf, bugBounty certifications[], vulnerabilities[] resources[] → resource ids platforms[] → platform ids commonMistakes[], related[], next[], tags[] lastVerified }

resource carries freeStatus, accountRequired, paymentRequired, regionRestrictions, qualityScore, relevanceScore, confidence, verificationMethod, backupResources.

assessment: {conceptId, passThreshold: 0.7, questions[{q, options, answer, explanation}]}
