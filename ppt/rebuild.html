Rebuild it from scratch

  1. Set up
    python3 -m venv .venv && pip install python-pptx requests Pygments; install Ollama, ollama pull qwen2.5:3b.
  2. Write the renderer first, with a hand-made JSON
    16:9 Presentation(), blank layout 6, a paper rectangle, header (accent bar + title), footer (deck title + number). Get a hard-coded deck looking right before any model is involved.
  3. Add fit_font_size
    the estimate on the blueprint page; loop from max to min pt in 0.5 steps. Use it for every text box.
  4. Add blocks
    bullets, text, callout, code, steps, cards, columns; render_blocks stacks by weight; then write slide_to_blocks so each type is a recipe.
  5. Code panel
    dark rounded rect, language label, Pygments lex() per line, map token types → colours; fall back to one colour.
  6. Schema
    normalize_presentation/slide/block: coerce types, infer type, force code layout, strip paired markdown, drop empties.
  7. Ollama client
    POST /api/chat with format:"json", stream:false; robust extract_json; merge_slide that only ever adds.
  8. Two-stage generator
    outline prompt (types, 4–12 slides, follow given structure) → cap sections → per-slide prompt with try/except fallback and [i/n] progress.
  9. CLI
    argparse: input, -o, --model, --ollama-url, --open.
