How I judge it

  • Timing: does the sticker land a beat after the moment, not on it?
  • Precision: false reactions from camera motion / crowd hallucinations kept low.
  • Density: reactions spaced, never a wall of stickers.
  • Speed: analysis ≈ 0.8× video length on a laptop GPU.
  • Reproducibility: same video + seed → same edit (unit-tested).

Rebuild it from scratch

  1. Frame sampler
    Decode the uploaded video to ~8 fps frames in the browser; no upload.
  2. Perception
    Run MediaPipe pose + face blendshapes + an object model per frame; GPU with CPU fallback; an upscaled head-crop pass for small faces.
  3. Camera + tracking
    Estimate cuts and global shift; a greedy IoU tracker with ids that reset at each cut.
  4. Detectors
    14 event types reading pose/face/objects/audio; confirm sustained, stamp onset; plausibility-gate hallucinations.
  5. Planner
    Score funniness; enforce spacing, per-type cooldown, density budget; map each type to instant/beat/delayed and sample a seeded delay.
  6. Placement + stickers
    Place beside the head on the roomier side; GIPHY search via a serverless proxy (fixed terms, CDN cache) with emoji fallback.
  7. Compositor
    One canvas renderer for both live preview and MediaRecorder export, keeping original audio.
  8. Ship
    Vite build + a serverless function on Vercel; unit tests via a synthetic-frame testkit.
